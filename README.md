# Medium Article Layout

A clean, responsive HTML/CSS recreation of a Medium-style article page. The layout includes a left navigation rail, a main article column with code blocks and callouts, and a right rail of recommendations.

## Features

- Three-column layout with responsive collapse to a single column
- Top navigation with search, write, and notifications
- Sidebar menu and membership call-to-action
- Article content with headings, code blocks, callout, and tags
- Recommendations and footer links in the right rail

## Usage

Open `index.html` in any modern browser.
